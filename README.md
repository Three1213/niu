# 安规刷题

Q/GDW 1799.1—2013《电力安全工作规程（变电部分）》第1~7章范围内的手机刷题页，共 1303 题（单选 742、多选 204、判断 318、简答 39）。其中 962 题标为"重点"，覆盖在规程 PDF 上圈画的全部 185 个条款，每条至少 1 题、多数 3 题以上。可按重点、章节（每一节）、知识点专项、智能复习或模拟考试练习。

- `index.html`：刷题页面（题库已内置）
- `sw.js`：离线缓存，打开过一次后断网也能用
- `icon.png`：添加到 iPhone 主屏幕时的图标

打开方式：用 Safari 访问本仓库的 GitHub Pages 网址，点"分享 → 添加到主屏幕"。
做题记录保存在各自手机的浏览器里，不会上传。
